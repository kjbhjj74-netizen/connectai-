## 3. 💻 코다리의 1인 개발 기술 스택 및 아키텍처 (아이템 1 기준)

1인 개발자는 **"유지보수 비용 제로, 초고속 배포"**가 생명입니다.

```
[고객사 웹사이트 / 카카오톡 채널]
              │ (Webhook / Widget)
              ▼
    [Next.js 14 + Tailwind CSS] (Vercel 배포)
              │
    ┌─────────┴─────────┐
    ▼                   ▼
[Supabase DB / Vector]  [LLM API / Ollama 로컬]
(고객사 지식 임베딩 RAG)  (의도 파악 및 답변 생성)
              │
              ▼
[구글 캘린더 / 슬랙 / 노션 자동 연동]
```

- **프론트/백엔드**: Next.js 14 (App Router) + TypeScript
- **데이터베이스/벡터 검색**: Supabase (무료 티어로 10개 이상 클라이언트 거뜬)
- **LLM 엔진**: OpenAI gpt-4o-mini 또는 Claude 3.5 Haiku (건당 비용 1원 미만으로 마진 95% 확보)
- **개발 기간**: 코어 엔진 5일 이내 완성 가능
